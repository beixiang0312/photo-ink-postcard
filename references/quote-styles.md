# 英文短句风格分类

根据照片最主要的情绪方向选择类别。类别键保留英文，以兼容选句脚本。

| 类别键 | 适合的画面线索 | 情绪方向 |
|---|---|---|
| `hope` | 黎明、薄雾、开阔天空、远处地标 | 温和的希望与可能性 |
| `courage` | 强烈建筑结构、陡峭透视、风雨光线 | 决心、勇气和迎难向前 |
| `persistence` | 铁路、重复桥跨、长路、航行中的船 | 坚持、耐力和持续努力 |
| `growth` | 山丘、树林、层叠天际线、扩展中的城市 | 学习、成长与成为 |
| `action` | 列车、船只、交通轴线、明确几何方向 | 行动、出发和当下推进 |
| `change` | 日落、天气变化、新旧场景对照 | 转变、更新和重新开始 |
| `future` | 天际线、地平线、高楼、开阔水面 | 面向未来的可能性 |
| `journey` | 道路、铁路、桥梁、船只、纵深轴线 | 远行、距离与前进 |
| `calm-resilience` | 雾气、安静水面、低调建筑 | 沉静、从容和稳定韧性 |
| `city-distance` | 越过山丘或水面眺望城市或聚落 | 地方向往和遥远视野 |

混合批次使用 `auto` 并避免重复。如果多个类别同样适合，优先选择当前批次中使用次数最少的类别。
